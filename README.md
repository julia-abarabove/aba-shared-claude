# aba-shared-claude

The A Bar Above team's shared Claude Code kit.

- New here? Start with [docs/getting-started.md](docs/getting-started.md).
- Install: [Windows](docs/install-windows.md) / [Mac](docs/install-mac.md).
- Team rules Claude follows: [CLAUDE.md](CLAUDE.md).
- Skills: `.claude/skills/`. Guardrails (what Claude may do without asking):
  `.claude/settings.json`.
- Connector setup references: `mcp-config-templates/`. No real tokens ever go
  in this repo.

Always start Claude Code from inside this folder so the team rules and skills
load.
