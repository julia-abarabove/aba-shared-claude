# Getting Started with Claude Code at ABA

## What this is

Claude Code is Claude running on your own computer, connected to the tools we
use. Week 1 connects it to **Asana**. More connections (email drafts, our
business data, WELL articles, Google Drive) come in later sessions.

You get your own helper in Asana called **"Claude (on behalf of <your
name>)"**. It's a separate Asana user that only you direct. You can assign it
a task, ask it to work the task, and it leaves comments with drafts and next
steps.

## Setup

- Windows: [install-windows.md](install-windows.md)
- Mac: [install-mac.md](install-mac.md)

## Your first task

1. In Asana, open a task you're stuck on or don't have time for.
2. Assign it (or add as a collaborator) to **Claude (on behalf of <your
   name>)**.
3. Start Claude Code (see "Every time after this" in your install guide) and
   type:

   > Work my Asana queue

   or paste the task link:

   > Work this task: <link>

4. Claude reads the task, tells you its plan, does the work, and posts a
   comment starting with `[Claude]`.
5. You read the comment and decide what happens next.

## The rule: Claude drafts, you close

Claude comments, drafts, and suggests. **You** decide what gets completed,
reassigned, or moved. Claude will ask you before changing a task's status,
assignee, due date, or location, and it can't delete anything.

Treat Claude's work like a draft from a smart new hire: usually good, always
worth a read.

## Good things to ask

- "Summarize what's happening on this task and what's blocking it."
- "Draft the email this task needs. Don't send it."
- "Break this task into subtasks."
- "What's on my Claude's plate this week?"
- "Research <topic> and put the findings on the task."

## Tips

- Talk to it like a person. Plain sentences work best.
- If it goes off track, just say "stop" or "that's not what I meant" and
  redirect.
- It forgets the conversation when you close it. Important context belongs in
  the Asana task, where it sticks.
- Type `/clear` to start a fresh conversation without closing the window.
